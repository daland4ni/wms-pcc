## Cloning and Setup Instructions using XAMPP:
```
1. Make sure you have XAMPP installed
2. Clone this repository on C:/xampp/htdocs
3. On the XAMPP control panel, turn start Apache and MySQL
4. On the MySQL row, press Admin. This should bring you to the phpMyAdmin site.
5. Import the SQL files in this repository
6. Go to localhost/wms-pcc
```
